---
request: Explain what an API is to someone with no background in it.
---
Every day, the apps on your phone talk to other companies' computers without you noticing. A weather app doesn't measure the temperature itself. It asks a weather service, and the service answers. That arrangement runs through something called an API, short for application programming interface.

An API is a set of rules one program follows when asking another program for something. The rules define what you can request, how to word the request, and what form the reply takes. You never see inside the other system. You only receive what it agrees to hand over.

Picture a restaurant kitchen. You don't walk in and start cooking. You read a menu, tell the waiter what you want, and a plate arrives. The menu limits your options, and the kitchen stays private. Software behaves the same way when it uses an API.

This matters because it lets companies build on each other's work instead of starting from scratch. An online shop can accept card payments without writing banking software. A travel site can display flights from dozens of airlines at once. Maps, logins, and chat features often arrive the same way.

So when you hear that two services "integrate," this is usually how.

In short, an API is a controlled doorway that lets one program request something from another.
